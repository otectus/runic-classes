# Runic Classes

The class layer of the Runic suite for Minecraft 1.20.1 Forge. After choosing a heritage and a race
(Runic Races), a player chooses one of thirteen classes, or stays Classless. A class is hard-wired into
Runic Skills:

- its two Aptitudes start at level 8, and their caps rise by 8;
- six class Perks appear under those Aptitudes in the Skills screen, for members only (two are active
  from the start, four unlock at 16, 16, 24 and 36);
- a class Runic Mark, Seal and Crown join the Powers screen, for members only, under every normal
  Runic Skills gate, slot and Power Point rule;
- the first confirmed class (Classless included) grants a one-time starter bag.

Classes are purely positive: no class has a drawback. The free starting levels extend the global level
budget by the same amount, so a class shapes where a player specialises, not how far.

Lore: [`docs/classes.md`](docs/classes.md). Every Perk and Power with its numbers: the in-game
tooltips, or `data/runicclasses/classes/*.json`. Design and rationale: [`docs/plan.md`](docs/plan.md).

## Requirements

- Runic Skills 2.4.0 or later (the class hooks), Origins Forge 1.10 or later.
- Optional: Runic Races (heritage and race come first), Treasure Bags (the starter bag is a bag rather
  than loose items), Iron's Spells 'n Spellbooks 3.16.3+ (the caster classes' spell branches; every caster
  Perk and Power has a vanilla fallback).

## Changing class

Use a **Class Orb**: it re-opens the class screen and nothing else (heritage and race have Runic Races'
Heritage Orb). The swap is wholesale: the old class's free levels, cap raises, Perks and Powers leave and
the new class's arrive; purchased levels stay, except that a level above the normal cap returns to it.
The starter bag is never granted again. Recipe: amethyst shards in the corners, lapis on three sides, an
ender pearl below and a book in the middle (datapack-overridable).

## Configuration and data

`runicclasses-server.toml`: `allowRepick`, `repickCooldownTicks`, `classlessGetsUniversalBag`,
`classFreeLevelsExtendGlobalCap`, `classFreeLevelsCountAsEarned`. `runicclasses-common.toml`:
`debugLogging`.

Every per-class number (stats, start level, cap bonus, Perk gate levels and magnitudes, starter bag) is in
`data/runicclasses/classes/<class>.json`, validated at reload: a broken edit is rejected and the previous
data stays live. Class Power cooldowns and magnitudes use Runic Skills' Power overrides
(`data/runicclasses/powers/<power>.json`). Starter bags are `data/runicclasses/loot_tables/bags/<class>.json`
with Treasure Bags types in `data/runicclasses/treasurebags_types/<class>_kit.json`.

## Commands

`/runicclasses info [player]`, and for operators `choose [player]`, `set <player> <class>`,
`reset <player>`, `bag give <player> [class] [force]`, `validate`, `diagnostics`.

## Building

Build `../runic-skills` first, then `python3 tools/sync_runicskills_lib.py`; place the Origins, Apoli,
Calio and Additional Entity Attributes jars in `Dependencies/`. `./gradlew build`, `./gradlew test`,
`./gradlew runGameTestServer`. Class data, lang and the registration table are generated by
`tools/generate_classes.py`; icons by `tools/generate_icons.py`.
