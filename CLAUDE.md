# Runic Classes - Forge 1.20.1 Mod

## Orientation
Registration inventory and package layout live in `MODMAP.md` (generated by
`.mcmod-tools/modmap.py`). Read that instead of crawling `src/`. The design is `docs/plan.md`.

## Quick Reference
- **Mod ID**: `runicclasses`
- **Package**: `com.otectus.runicclasses`
- **MC / Loader / Java / Mappings**: see `gradle.properties` (Parchment, like Runic Skills)
- **Network**: channel `runicclasses:main`, protocol `"1"` (`network/RCNetwork`); class state schema `ClassState.DATA_VERSION`

Version numbers live only in `gradle.properties`; `processResources` expands them into `mods.toml`
and `pack.mcmeta`. Never hard-code one elsewhere, this file included.

## Build
- First: build `../runic-skills`, then `python3 tools/sync_runicskills_lib.py` (copies the jar into gitignored `libs/`)
- `Dependencies/` holds the Origins/Apoli/Calio/AEA jars (gitignored; the same files Runic Races uses)
- `./gradlew compileJava` - iteration; `./gradlew build` - jar in `build/libs/`
- `./gradlew test` - JUnit: `ClassBudgetTest`, `ClassDataParityTest` (runs the generator in `--check` mode)
- `./gradlew runGameTestServer` - GameTests; fails unless the log says "All N required tests passed"

## Structure
```
data/          ClassIds (layer/origin keys, read by the Ultima bridge), definitions, loader, validator, ClassKit (GENERATED)
service/       ClassHelper (selection + memo), ClassReconciler (diff/undo/apply/ensure), StarterBagService, RepickService
state/         ClassState capability: what has been granted, never which class is chosen (Origins owns that)
registry/      RCPerks / RCPowers register into Runic Skills' registries; RCItems (Class Orb); RCEffects (auras)
kit/           KitDispatcher routes Forge events to the acting player's class modules; shared combat helpers
perk/handlers/ power/handlers/   one module per class, implementing kit/ClassModule
integration/   runicskills (hook installer), irons (typed half loaded by name only), treasurebags (reflection)
client/        packet handlers, Skills-screen class badge; common code reaches it only through DistExecutor
```

## Key Dependencies
- Runic Skills (`runicskills_version`, mandatory) - hard-wired through its 2.4.0 hooks (`SkillCapHooks`,
  `ContentGateHooks`, `ProgressionHooks.levelUpDiscount`, `RespecEvent`); Runic Skills must never import this mod
- Origins Forge (mandatory) - the class is the `runicclasses:class` layer, order 20
- Iron's Spells (optional, compile-only) - only `integration/irons` names its types; every caster effect has a vanilla fallback
- Treasure Bags (optional, no compile dependency) - the starter bag is a bag when present, plain items otherwise

## Conventions
- MOD bus: DeferredRegisters, capability registration, common setup. FORGE bus: `ClassLifecycleHandler`, `KitDispatcher`
- Config: `ForgeConfigSpec` SERVER (behaviour switches, synced to clients) and COMMON (`debugLogging`); per-class
  numbers live only in `data/runicclasses/classes/*.json`, class Power tuning in Runic Skills' power overrides
- Class Perk/Power paths must stay globally unique (`cls_<class>_<slug>`): Runic Skills keys caches by path
- No mixins, no access transformers. Private vanilla fields go through `ObfuscationReflectionHelper` with SRG names
- Generated, never hand-edit: class/origin/layer/display-power/bag JSON, `en_us.json`, `ClassKit.java`,
  `docs/classes.md` (`tools/generate_classes.py`, prose in `tools/class_lang.json`); icons (`tools/generate_icons.py`)

## Terminology
- "Aptitude" = a Runic Skills skill (Strength ... Tinkering); "class stat" = the class's primary/secondary Aptitude
- "Applied" = granted by this mod (`ClassState`); "selected" = chosen on the Origins layer
